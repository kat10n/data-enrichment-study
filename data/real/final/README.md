# Итоговый набор ручного обогащения

- `texts.jsonl` содержит 200 сообщений, по 100 с метками `spam` и `not_spam`.
- `photos/annotations.coco.json` содержит 137 кадров. Из них 71 с животными и 66 пустых. Всего 115 рамок класса `animal`.
- `photos/images/` содержит исходные файлы кадров. Поле `file_name` в COCO задано относительно папки `photos/`.
- `photos/sources.jsonl` связывает кадры с источниками и контрольными суммами. У 28 кадров в исходных материалах отсутствует лицензия.

Согласованные решения взяты из `artifacts/annotation_comparison/adjudication_template.json`. Остальные примеры имеют совпадающие метки или статусы A и B. Для кадров вне списка разбора использованы рамки A. Рамки переведены из процентов Label Studio в пиксельные координаты COCO `[x, y, width, height]`. У пустого кадра в COCO есть запись в `images` и нет записей в `annotations`.

Кадры `IMG064`, `IMG099` и `IMG117` исключены при согласовании.
